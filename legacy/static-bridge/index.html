Install in AniKatha (Android)

Use the separate anime-routing fixture manifest (not the Stremio movie manifest):

anikatha/manifest.json

  1. Open AniKatha → Profile → Content & discovery → Manage add-ons.
  2. Paste the public HTTPS AniKatha manifest URL and tap Add source.
  3. Browse the static compatibility fixture, open its sample title and play its clip.

Big Buck Bunny is not anime; its anime type is used only to test AniKatha routing. Playback depends on the app and media host. No providers are integrated.
