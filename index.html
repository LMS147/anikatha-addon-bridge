Install in AniKatha (Android)

  1. Copy the manifest URL above (it must be a public https:// URL).
  2. Open AniKatha → Profile → Content & discovery → Manage add-ons.
  3. Paste the URL and tap Add source. “AniKatha Bridge” should appear in the list.
  4. Close and reopen AniKatha — the entry should still be listed.

AniKatha validates that the manifest has an id and stores it locally. Catalog playback from add-ons is handled by AniKatha’s own adapters; this bridge proves the shared install flow.
